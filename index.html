02 // EXECUTIVE INTEGRITY MANDATE
Mandatory Protocol Notice: Zero Legacy Migration

Complete Retirement of LocalStorage & Clean Season 2 Reset

In V2.x, competitor ratings and match logs were stored in browser localStorage. Because client-side storage can be manually edited via browser DevTools, importing legacy browser state into the global cloud leaderboard would compromise competitive integrity.

Effective with V3.3 deployment, LocalStorage persistence is permanently retired. There is no legacy data import or migration bridge. Every competitor begins Season 2 on an identical, verifiable baseline upon authenticating with Google.
